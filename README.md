# 掲示場巡回（PWA）

選挙ポスターの掲示場を、**迷わず・漏れなく回って、貼った記録を残す**ためのWebアプリです。スマホのブラウザで開き、ホーム画面に追加すると、アプリのように全画面で使えます。

- ハッカソンで作った試作です。

## できること

- **掲示場の一覧を CSV で取り込む**: 列は見出しや値から自動で判断します（UTF-8・Shift_JIS 対応）。読めない行は、行番号と理由を表示します。
- **出発地点（自宅）を地図で選ぶ**: 地図を押すか印を動かして決めます。現在地を使うこともできます（位置は端末の中だけに保存）。
- **巡回順を出す**: 出発地点を最初と最後にして、直線距離で近い順に並べ、入れ替えで縮めます（最近傍法＋2-opt）。実際の道のりではなく目安です。
- **地図で全体を見る**: 番号つきの印・出発地点・巡回順の線。印を押すと案内を始められます。
- **案内は Google マップアプリに渡す**: 目的地を渡すだけです（[Maps URLs](https://developers.google.com/maps/documentation/urls/get-started)、API キー不要）。
- **撮影で完了**: 写真の保存ができて初めて「完了」になります。撮影を取り消すと未完了のままです。
- **オフライン**: 一度開けば、電波がなくても開けます。見た範囲の地図も保存します。

## データとプライバシー

- **データはあなたの端末の中だけに保存され、ほかの人からは見えません。** 開発者を含め、誰にも送られません（「Google マップで案内」を押したときに、その目的地だけが Google マップに渡ります）。
- 出発地点・一覧・進捗・写真は、**その端末のブラウザの中（IndexedDB）にだけ**保存します。サーバーには送りません。
- 写真は長い辺1600pxの JPEG に縮めて保存し、位置情報などのメタデータは残しません。
- 「Google マップで案内」を押すと、目的地が Google マップに渡ります。

## 地図と外部の素材

| 素材 | 使い方 | ライセンス・出典 |
| --- | --- | --- |
| [Leaflet](https://leafletjs.com/) 1.9.4 | 地図の表示。unpkg から版を固定し、改ざん検出（SRI）つきで読み込む | BSD-2-Clause |
| [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html) | 背景地図（淡色地図・標準地図） | 出典: 国土地理院 |
| Google マップ | 案内のときに、目的地を渡してアプリを開くだけ | 地図表示に Google Maps Platform の API は使っていません |


## 掲示場データについて

このリポジトリには、**架空の見本データ（10か所）だけ**を入れています。実際の掲示場の一覧は、各自治体の選挙管理委員会が公開する資料やオープンデータから入手し、利用条件と出典の表示に従って取り込んでください。

- 例: 自治体のオープンデータカタログ（[BODIK](https://data.bodik.jp/) など）で「ポスター掲示場」を検索すると、CSV で公開している自治体が見つかります。利用条件（ライセンス）と出典の表示に従ってください。
- 掲示場は選挙ごとに変わります。必ずその選挙の一覧を使ってください。

## 使うときの注意

- **運転中は操作しないでください。** 停車してから、または同乗者が操作してください。
- 選挙での利用にあたっては、公職選挙法などのルールを守ってください。このアプリは法的な助言を提供するものではありません。疑問は各選挙管理委員会にご確認ください。

## 開発

```bash
# 動かす（http://localhost:8781）
python3 -m http.server 8781 --bind 127.0.0.1

# 試験
node test/core.test.mjs
```

| ファイル | 中身 |
| --- | --- |
| `index.html` / `style.css` | 画面の枠と見た目 |
| `js/app.js` | 画面（巡回順・次の掲示場・撮影・地図・設定・CSV取り込み） |
| `js/core.js` | 計算（CSV・列の割り当て・行の検査・巡回順・URL） |
| `js/store.js` | 端末内の保存（IndexedDB） |
| `sw.js` / `manifest.webmanifest` / `icons/` | オフライン対応とホーム画面への追加 |
| `data/sample.csv` | 架空の見本（10か所。位置は目安） |
| `test/` | 試験（データはすべて架空） |

### 秘密情報を入れないために

- API キーやトークンは使いません。`.env`・`.vercel/`・鍵ファイルは `.gitignore` で除外しています。
- push のたびに [gitleaks](https://github.com/gitleaks/gitleaks) で秘密情報を検査します（`.github/workflows/ci.yml`）。
- 実在の人の住所や、利用条件を確認していないデータは入れないでください。
