# 掲示場巡回（PWA）

選挙ポスターの掲示場を、**迷わず・漏れなく回って、貼った記録を残す**ためのWebアプリです。スマホのブラウザで開き、ホーム画面に追加すると、アプリのように全画面で使えます。

- ハッカソンで作った試作です。端末やブラウザによっては、うまく動かないことがあります。

## できること

- **掲示場の一覧を CSV で取り込む**: 列は見出しや値から自動で判断します（UTF-8・Shift_JIS 対応）。読めない行は、行番号と理由を表示します。複数の一覧を取り込んで、切り替え・削除ができます。
- **担当を選ぶ**: 一覧の中から、自分が回る掲示場を選びます。番号や名前で絞り込めます。
- **出発地点（自宅）を地図で選ぶ**: 地図を押すか印を動かして決めます。現在地を使うこともできます（位置は端末の中だけに保存）。
- **巡回順を出す**: 出発地点を最初と最後にして、直線距離で近い順に並べ、入れ替えで縮めます（最近傍法＋2-opt）。実際の道のりではなく目安です。
- **地図で全体を見る**: 番号つきの印・出発地点・巡回順の線。印を押すと案内を始められます。
- **案内は Google マップアプリに渡す**: 目的地を渡すだけです（[Maps URLs](https://developers.google.com/maps/documentation/urls/get-started)、API キー不要）。
- **撮影で完了**: 写真の保存ができて初めて「完了」になります。撮影を取り消すと未完了のままです。
- **オフライン**: 一度開けば、電波がなくても開けます。地図は、電波のある場所で一度表示した範囲だけを保存します（地図画像は最大3,000枚。古いものから消えます）。
- **見本で試す**: 架空の掲示場10か所の見本が入っています。

## CSV の形

- 使う列: **番号・掲示場名・緯度・経度**（必須）と、**設置場所**（あれば）。列の名前が「図面表示番号」「名称」「lat」などでも自動で割り当て、分からないときは画面で選べます。
- 緯度・経度は、十進の度で書いてください（例: `35.6812` と `139.7671`）。
- 上限: ファイルは5MB、行は10,000行、値の入った列は200列まで。番号・掲示場名・設置場所が2,000文字を超える行は取り込みません。
- 同じ名前の一覧がすでにあるときは、「別の一覧として追加」か「置き換える」を選べます。**置き換えると、新しい一覧にない番号の写真と、位置が50mを超えて変わった掲示場の写真は消えます**（消す前に件数を示して確認します）。

## データとプライバシー

- **データはあなたの端末の中だけに保存され、ほかの人からは見えません。** 出発地点・一覧・進捗・写真は、その端末のブラウザの中（IndexedDB）に保存します。このアプリには、それらを集めるサーバーがありません。
- **端末の中にしかないので、ブラウザのデータを消すと、一覧・進捗・写真はすべて消えます。** 元に戻せません。写真を書き出す（バックアップする）機能はありません。端末をなくした場合も同じです。
  - ブラウザによっては、しばらく使わないサイトのデータを自動で消すことがあります。ホーム画面に追加して使うと、消されにくくなります。
- 写真は長い辺1600pxの JPEG に縮めて保存し、位置情報などのメタデータは残しません。
- 端末の外とのやり取りは、次のとおりです。
  - **Google マップ**: 「Google マップで案内」を押すと、目的地（掲示場の位置。帰宅の案内では自宅の位置）が Google マップに渡ります。このアプリが渡すのは目的地だけですが、案内では Google マップが現在地も使うため、現在地と目的地が Google に伝わります。
  - **国土地理院**: 地図を表示するとき、見ている範囲の地図画像を取得します。自宅や掲示場の位置そのものは送りませんが、表示した範囲は国土地理院のサーバーに伝わります。「自宅を地図で選ぶ」では自宅の周りを拡大して表示するので、表示した範囲からおおよその場所が分かります。
  - **unpkg**: 地図の部品（Leaflet）を取得します。取得したものは端末に保存し、できるだけそれを使い回します。
  - 国土地理院と unpkg から取得するときは、ブラウザの標準の動きで、このアプリのドメイン名も相手に伝わります（ページのアドレスのそれ以外の部分は伝わりません）。
  - **アプリの配信元**: アプリ本体のファイルを取得します。ほかの Web サイトと同じく、配信元にアクセスの記録（IP アドレスなど）が残ることがあります。
- 「現在地を使う」は、端末とブラウザの位置情報の機能を使います。取得した位置は、端末の中だけに保存します。

## 地図と外部の素材

| 素材 | 使い方 | ライセンス・出典 |
| --- | --- | --- |
| [Leaflet](https://leafletjs.com/) 1.9.4 | 地図の表示。unpkg から版を固定し、改ざん検出（SRI）つきで読み込む | BSD-2-Clause |
| [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html) | 背景地図（淡色地図・標準地図） | 出典: 国土地理院 |
| Google マップ | 案内のときに、目的地を渡してアプリを開くだけ | 地図表示に Google Maps Platform の API は使っていません |

## 掲示場データについて

このリポジトリには、**架空の見本データ（10か所）だけ**を入れています。実際の掲示場の一覧は、各自治体の選挙管理委員会が公開する資料やオープンデータから入手し、利用条件と出典の表示に従って取り込んでください。

- 例: 自治体のオープンデータカタログ（[BODIK](https://data.bodik.jp/) など）で「ポスター掲示場」を検索すると、CSV で公開している自治体が見つかります。利用条件（ライセンス）と出典の表示に従ってください。
- 掲示場は選挙ごとに変わります。必ずその選挙の一覧を使ってください。

## 使うときの注意

- **運転中は操作しないでください。** 停車してから、または同乗者が操作してください。
- 電波のない場所へ行く前に、電波のある場所で担当の範囲の地図を一度表示しておいてください。表示していない範囲の地図は、電波がないと出ません。
- **同じ端末で、このアプリを複数のタブやウィンドウで同時に開かないでください。** 片方で一覧を切り替えるなどすると、もう片方で撮った写真が保存されないことがあります。
- 「見本を入れる」を押すと、登録した自宅が見本の位置に置き換わります。見本で試したあとは、自宅を登録し直してください。
- 選挙での利用にあたっては、公職選挙法などのルールを守ってください。このアプリは法的な助言を提供するものではありません。疑問は各選挙管理委員会にご確認ください。

## 開発

ビルドは不要です。ファイルをそのまま配信すれば動きます。位置情報とオフライン対応は、HTTPS か localhost でしか動かないので、公開するときは HTTPS で配信してください。

```bash
# 動かす（http://localhost:8781）
python3 -m http.server 8781 --bind 127.0.0.1

# 試験
node test/core.test.mjs
```

上の「動かす」は、フォルダの中身をすべて配信します。秘密情報のファイルをフォルダに置いたまま使わないでください。

| ファイル | 中身 |
| --- | --- |
| `index.html` / `style.css` | 画面の枠と見た目 |
| `js/app.js` | 画面（巡回順・次の掲示場・撮影・地図・設定・CSV取り込み） |
| `js/core.js` | 計算（CSV・列の割り当て・行の検査・巡回順・URL） |
| `js/store.js` | 端末内の保存（IndexedDB） |
| `sw.js` / `manifest.webmanifest` / `icons/` | オフライン対応とホーム画面への追加 |
| `data/sample.csv` | 架空の見本（10か所。位置は目安） |
| `test/` | 試験（データはすべて架空） |

### 秘密情報を入れないために

- API キーやトークンは使いません。`.env`・`.vercel/`・鍵ファイルは `.gitignore` で除外しています。
- Vercel のコマンドで公開するときは、`.vercelignore` にも同じ除外を書いてください。
- push のたびに [gitleaks](https://github.com/gitleaks/gitleaks) で秘密情報を検査します（`.github/workflows/ci.yml`）。
- 実在の人の住所や、利用条件を確認していないデータは入れないでください。
